Honest limits (documented in PHASES.md for shipped phases)
  • Compliance name-matching: guard-drop, ceiling height, handrail height (IBC & ADA) are name-match only — no geometric guard/handrail/fixture modeling. ADA reach ranges, door maneuvering clearances, restroom fixture clearances, handrail extensions are skipped (model carries no fixture/height/swing geometry).
  • Travel distance (IBC 1017.2): straight-line room-centroid → nearest exit, not the routed egress path; exit-count uses a proximity heuristic (exits within the room half-diagonal), not a door-graph.
  • Door/threshold checks: door clear width from param-block width×scale, else block-def plan extent; ADA threshold is param-only (no small-step mesh geometry).
  • M-perf: Step 2 (wgpu GPU compute) deferred by design. Step-1 rayon deliberately skips minsurf/force_density (Gauss–Seidel, sequential), dynamic_relaxation (order-dependent float scatter), LAZ/E57 streams, OBJ/glTF/Collada stateful parsers.
  • M-secreview: DXF and EPW parsers have no dedicated adversarial corpus yet; a broader fuzz harness (cargo-fuzz per importer) is the noted next step.
  • M-landscape (partial pieces NOT done): contour labels + sheet/PDF feed, freeform grade regions, retaining-edge detection, plantmass, seasonal deciduous transparency, watershed accumulation, swale, stairs/ramp generators, site sections through terrain.
  • Plan symbols NOT done: seasonal deciduous stipple density, per-species custom art, symbol in DXF export.
  • M-deckagent: run_plan_loop is mock-tested but not yet the live execution path (the streaming deck_pane driver is); no dedicated per-step GBNF "STEP" form.
  • Code signing (M-sign, deprioritized): the app is unsigned / ad-hoc-signed, so macOS re-prompts for keychain access after each rebuild and Gatekeeper warns on first launch. Chat encryption is therefore default OFF for now; flip back to default-ON once a stable Developer ID signature makes the "Always Allow" grant stick. Ship-gate decision for v0.1.

How to run these tests

  1. Launch dist/ItsJustCAD.app. Start each group from a fresh document (⌘N) unless a step says to build on the previous.
  2. Commands are typed in the command line (bottom, full-width) or the deck Chat — both accept the same verbs. Selectors: last = most recent object, sel = current selection, name:foo = by name.
  3. Tick each box as you verify the expected result. Boxes persist in this browser (localStorage).
Every analysis/compliance/advisory output is intentionally worded as advisory — the app never claims to certify or analyze structurally.

10 · Chat Encryption shipped · opt-in

AES-256-GCM at rest, keyed by an OS-keychain data key; default OFF, toggled with chatencryption on|off (alias encryptchats). Key cached per process → at most one keychain prompt per launch. Self-describing format loads plaintext or encrypted either way, so toggling is lossless.
