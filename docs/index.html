It's just CAD.

A complete architect's CAD in a single ~10 MB binary — modelling, drafting, environmental analysis, and site planning — with an LLM drafting partner built into the app that draws with the same commands you type.

One command substrate, human and machine

The whole app is a command language. Your typed commands, the mouse tools, and the LLM all flow through one path — a click-drawn rectangle and an LLM-drawn rectangle are the exact same operation. And the file you save is not geometry: it's the ordered op-log of commands that built the model, so you get perfect undo, history editing, and clean git diffs for free.

# type these into the command bar
box 0,0,0 40,30,4       # a podium
box 6,6,4 20,14,24      # a tower
plan 1.5                # cut a plan
sheet plan-01 a3        # a paper sheet
sheetview plan-01 top 1:100
print plan-01 plan.pdf  # vector PDF at scale

Or tell the deck, in plain language:

"make a 40×30 podium with a tower on top,
 cut a plan, and print an A3 sheet"

— it emits those same commands as cards you can inspect, undo, or amend. No second code path.

What it does

A working architect's toolkit, not a tech demo.

Model & draft

Boxes, extrude, revolve/loft/sweep, in-repo CSG booleans, NURBS curves, 2D sketch constraints, blocks. Plan/section cuts, elevations, dimensions, hatches, sheets (A4–A0), and vector PDF export.

Site planning (intemfit)

From one boundary: generate streets and blocks, subdivide into lots, apply setbacks, place buildings, and read a gross-vs-net yield report with GFA, FAR, and coverage.

Environmental analysis

Real solar position (NOAA SPA), shadow studies, sun-hours and per-face insolation heatmaps, annual radiation from EPW weather, sun-path diagrams — every study stores numbers to design with.

Compliance pre-checks

Geometric pre-checks against embedded IBC-2021 egress and ADA-2010 packs, with per-rule verdicts. Advisory only — never a code review.

Landscape & planting

Terrain from survey points, contours, grading and earthwork, a 33-species planting catalog (temperate + Caribbean / Latin-American tropical), and advisory drainage.

Exchange

Import/export DXF, OBJ, STL, glTF, IFC4, 3DM (Rhino), SVG, PDF, and point clouds — plus assisted DWG import and a SAF structural handoff. Hand-written, minimal dependencies.

Localized & skinnable

English and Spanish ship in-app (switch anytime). The UI skins itself to the CAD you came from — AutoCAD, Rhino, or Revit — with matching colors and command aliases.

Embedded local-LLM deck

An LLM partner that draws, teaches, plans multi-step work, and critiques designs in numbers — running a local model, a cloud model, or nothing at all. It ships with no backend active.

Download & install

One file. No installer, no dependencies, no account. Get the latest release →

Your OSFirst launch
macOS (Apple Silicon or Intel)Unpack ItsJustCAD.app, then right-click ▸ Open (once).
Windows (x86-64)Unzip, double-click, More info ▸ Run anyway (once).
Linux (x86-64)tar xzf …, chmod +x itsjustcad, then run.

The app is not code-signed yet, so your OS shows a one-time "unidentified developer" warning on the very first launch. Use the step above; after that it just opens. It's a single ~10 MB program with nothing to install.

Free, open, and honest

The desktop app is free and open source under AGPL-3.0-or-later — use it, fork it, build on it. The file format and command language are documented and stable. A separate paid mobile edition funds the polish, so this isn't a donation-starved side project.

Advisory-only disclaimer. ItsJustCAD's compliance pre-checks, structural metadata, site-planning envelopes, and environmental studies are design-stage aids, not professional certification. The app never certifies code compliance and never performs structural analysis. Verify allowable use, zoning, egress, accessibility, and structure with a licensed professional and the authority having jurisdiction.
