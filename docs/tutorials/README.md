# Tutorials

Guided, step-by-step walkthroughs for people who want to *do* something, not
just look up a verb. Each one is written so a working architect can follow it
top to bottom and end with a real result on screen.

| # | Tutorial | You end with |
|---|---|---|
| 1 | [Getting started](01-getting-started.md) | Your first document — a massing, orbited, saved, and printed to a PDF sheet |
| 2 | [Site planning with intemfit](02-site-planning.md) | A subdivided site with buildings and a yield report |
| 3 | [Environmental analysis](03-environmental-analysis.md) | A sun-hours study you can read in numbers and have the deck critique |
| 4 | [Working with the deck](04-deck.md) | The LLM drawing and analysing with you, in the same commands you type |

These are the long-form companions to the terse
[command reference](../command-reference.md), which lists every verb with its
exact usage. When a tutorial names a command, the reference is where you go for
the full signature.

Everything here is typed into the **command bar** at the bottom of the window,
one command per line, Enter to run. The same commands work from a script file
(`ItsJustCAD --run script.txt`) and from the deck.
